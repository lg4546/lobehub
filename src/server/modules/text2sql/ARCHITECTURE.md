## 查询流程图

```
用户Query: "查询上个月消费超过1万的客户"
    │
    ▼
┌─────────────────────────────────────────┐
│  1. 对话管理器 (Dialog Manager)         │
│  - 获取会话上下文                        │
│  - 检测是否为follow-up query            │
│  - 解析引用关系                          │
└──────────────┬──────────────────────────┘
               ▼
┌─────────────────────────────────────────┐
│  2. NLU模块 (Natural Language Understanding) │
│  Intent: aggregation (0.9)              │
│  Entities: [date: last_month, number: 10000, │
│            entity: customer, operator: >]     │
└──────────────┬──────────────────────────┘
               ▼
┌─────────────────────────────────────────┐
│  3. 表选择器 (Table Selector)           │
│  - 生成query embedding                  │
│  - 搜索schema embedding                 │
│  - 选出相关表:                           │
│    • customers (0.85)                   │
│    • orders (0.92)                      │
└──────────────┬──────────────────────────┘
               ▼
┌─────────────────────────────────────────┐
│  4. DSL生成器 (DSL Generator)           │
│  - 检索相似Query-SQL示例 (Few-shot)      │
│  - 构建Schema-aware Prompt              │
│  - LLM生成SQL                           │
│  Generated SQL:                          │
│  SELECT c.id, c.name, SUM(o.amount)     │
│  FROM customers c JOIN orders o         │
│    ON c.id = o.customer_id             │
│  WHERE o.order_date >= DATE_SUB(...)    │
│    AND o.order_date < CURDATE()         │
│  GROUP BY c.id, c.name                  │
│  HAVING SUM(o.amount) > 10000           │
└──────────────┬──────────────────────────┘
               ▼
┌─────────────────────────────────────────┐
│  5. SQL验证器 (SQL Validator)           │
│  ✅ 语法检查: PASSED                    │
│  ✅ 语义检查: PASSED                    │
│  ✅ 安全检查: PASSED                    │
│  ⚠️  性能建议: 建议在order_date上建索引  │
└──────────────┬──────────────────────────┘
               ▼
┌─────────────────────────────────────────┐
│  6. 数据访问层 (Data Access Layer)      │
│  - 应用Row-Level Security               │
│  - 执行SQL                              │
│  - 脱敏敏感字段                          │
│  - 格式化为Markdown                     │
└──────────────┬──────────────────────────┘
               ▼
┌─────────────────────────────────────────┐
│  7. 返回结果                            │
│  | 客户ID | 客户姓名 | 消费总额 |        │
│  |--------|---------|---------|        │
│  | 1001   | 张三    | 15000   |        │
│  | 1002   | 李四    | 12000   |        │
│                                          │
│  执行时间: 125ms                         │
│  SQL置信度: 0.92                        │
└─────────────────────────────────────────┘
```

## 关键特性

### ⭐ 新增核心模块

1. **表选择器** - 智能识别相关表，减少LLM搜索空间
2. **DSL生成模型** - Few-shot学习，提升SQL生成准确率
3. **SQL验证器** - 多层级验证，自动修正常见错误
4. **错误样例库** - 从失败中学习，持续优化系统

### 🔒 安全特性

- SQL注入检测
- 行级安全过滤 (Row-Level Security)
- 列级字段脱敏
- 危险操作拦截

### 🚀 性能优化

- Schema embedding预加载
- 查询结果缓存 (Redis/Memory)
- 按业务分类的示例库
- 索引使用分析

### 💬 对话能力

- 多轮对话上下文
- 引用解析 (代词、指示词)
- 槽位填充
- 意图追踪
